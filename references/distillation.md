# 转录、证据与金线提炼

## 转录

优先可靠原字幕；否则抽取 16 kHz 单声道音频供语音识别，保留原片音轨。长视频可分块识别并缓存；每块输出转换回全片时间码。若块有重叠，需消除边界重复并核对词句，不能简单拼接。只在模型实际已缓存时使用离线模式。

保存原始 ASR JSON、带时间码字幕、易读稿。易读稿可加标点和分段，但不得以总结替代完整逐字稿。音乐、静音幻觉、重复识别、专名不确定和听不清处要标记；修订保留依据。不要把 ASR 自带置信信息等同于准确率。

## 阶段提示词

按真实操作顺序建阶段：目标 → 工具/输入素材 → 原始提示 → 追问与修改 → 结果 → 注意事项。教程屏幕中的完整提示词必须查看对应画面；口述转录无法证明屏幕原文。

每条保留源时间码，使用明确类别：

- **屏幕核对原文**：实际可见且已核对的输入；遮挡部分注明，不补猜。
- **口述整理**：讲者说出的指令，说明有标点或口语整理。
- **改写复用模板**：根据方法重新写的模板，变量使用占位符，不能冒充原始输入。

区分用户输入、模型回复、自动补全、聊天评论与讲者解释。同一阶段多轮迭代合并成有顺序的记录，不能只留最后一句而漏掉素材和约束。未能读取画面时，可先交付口述版，并明确屏幕核对尚未完成。

## 金线与 MECE

默认一页纸五问，每段 1–3 个核心点；复杂课程另附详细阶段表，不为凑短篇幅遗漏重要环节。

1. 是什么：对象、定位、一句话本质。
2. 为什么：问题、动机、价值。
3. 怎么做：依赖关系清楚的步骤与验证动作。
4. 用什么：工具、素材、提示词、模板。
5. 注意点：边界、失败原因和待证实内容。

重复观点合并并交叉引用，关键内容均有归属；“缺失要点”只能从来源补证，不能凭常识冒充视频内容。个人推论与视频陈述分开。教程工具名、产品效果及外部统计未独立验证时写“讲者称”，不要写成已验证事实。

## 按需交付

- 整体总结：主题、内容主线、阶段关系、主要结论、可执行方法、局限。
- 优缺点：每项包含时间码证据、具体表现、影响和改进建议；区分内容质量、表达质量与工具操作效果。
- 重点：概念、方法、案例与行动项，避免同一观点重复列入多处。
- 金句：逐字核对的原话配时间码；润色后标“改写金句”，不给讲者加引号归因。
- 提示词清单：覆盖请求范围的全部可辨认阶段，同时声明屏幕核对范围。

这些输出按用户请求选择；只要下载时不自动转录，只要总结时不默认制作视频。
